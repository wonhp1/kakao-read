# kakao-read

카카오톡 PC 화면을 **읽기만** 하는 도구를 윈도우로 옮기기 위한 저장소입니다.

macOS 버전은 접근성(AX) 기능으로 방 창의 메시지를 읽습니다. 서버 접속·로그인·DB 복호화·클릭이 없습니다.
윈도우에도 같은 방식인 **UI Automation(UIA)** 이 통하는지 먼저 확인해야 해서, 확인용 스크립트를 올려 둡니다.

## 확인용 스크립트 — `probe/kakao_win_probe.py`

하는 일은 세 가지입니다.

- 방 창 아래의 Win32 창 구조(클래스 이름, 창 글자)를 덤프합니다.
- UIA 트리 전체를 덤프합니다. 숨은 노드까지 보이도록 RawView로 읽습니다.
- 화면에 보이는 메시지 문구(`--expect`)가 어느 노드의 어느 속성에서 나오는지 찾아 **가능 / 못 찾음**을 판정합니다.

**하지 않는 것**: 창을 앞으로 가져오기, 포커스 옮기기, 클릭, 키 입력, 클립보드 사용, 시스템 설정 변경.

### 준비

1. Windows 10 또는 11에서 카카오톡 PC에 로그인해 둡니다.
2. uv를 설치합니다. PowerShell에서 아래를 실행합니다.

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

3. 이 저장소를 받습니다.

   ```powershell
   git clone https://github.com/wonhp1/kakao-read.git
   cd kakao-read
   ```

처음 실행할 때 uv가 Python과 `comtypes`를 알아서 받습니다.

### 실행

1. 확인할 방을 카카오톡 목록에서 **더블클릭해 별도 창으로** 엽니다. 최소화하지 마세요. 다른 창 뒤에 가려 있는 것은 괜찮습니다.
2. 창 제목을 확인합니다.

   ```powershell
   uv run probe/kakao_win_probe.py windows
   ```

3. 확인합니다. 방 이름은 2번에서 본 제목을 그대로 씁니다. `--expect`에는 **그 방 창에 지금 보이는 메시지 일부**를 넣습니다.

   ```powershell
   uv run probe/kakao_win_probe.py probe "방 이름" --expect "화면에 보이는 메시지 일부"
   ```

참고할 점이 두 가지 있습니다.

- 읽는 동안 카카오톡이 잠깐 버벅일 수 있습니다. 노드마다 카카오톡에 속성을 물어보기 때문입니다.
- 카카오톡을 **관리자 권한으로 실행했다면** PowerShell도 관리자 권한으로 열어야 합니다. 그렇지 않으면 창 정보를 읽지 못합니다.

### 결과 보기

화면 맨 끝의 `[판정]`을 봅니다.

| 판정 | 뜻 | 다음 단계 |
|---|---|---|
| 가능 | UIA에서 메시지 글이 나옵니다 | 맥처럼 창을 건드리지 않고 읽는 버전을 만듭니다 |
| 부분 가능 | Win32 창 글자에서만 나옵니다 | 그 경로로 만들 수 있는지 봅니다 |
| 못 찾음 | 어디에도 나오지 않습니다 | 아래 순서로 확인합니다 |

**못 찾음**이 나오면 이렇게 확인합니다.

1. 그 문구가 방 창에 지금 보이는지 확인합니다.
2. (선택) 무료 스크린리더 NVDA를 켠 채로 카카오톡을 완전히 껐다 켜고 다시 확인합니다. 스크린리더가 켜져 있을 때만 접근성 정보를 내주는 앱이 있습니다.
3. 그래도 없으면 클립보드 복사 방식을 검토합니다. 이 방식은 창이 앞으로 뜨고 클립보드를 씁니다.

자세한 내용은 `probe-report.json`에 남습니다. 이 파일을 Claude에게 보여 주면 다음 단계를 만듭니다.

### 개인정보

- `probe-report.json`에는 대화 일부가 들어 있습니다.
  - 긴 글은 앞 8자만 남깁니다(`--full`을 주면 전체).
  - 날짜·시각만으로 된 글은 형식을 봐야 해서 그대로 남깁니다.
- 이 파일은 `.gitignore`에 들어 있습니다. **공개 저장소에 올리지 마세요.**

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--expect 문구` | 찾을 문구. 여러 번 줄 수 있습니다 |
| `--hwnd 0x…` | 제목이 같은 창이 여럿일 때 창을 지정합니다(`windows`에 나온 값) |
| `--depth` / `--max-nodes` / `--max-seconds` | UIA 트리를 읽는 한도(기본 30 / 4000 / 90초) |
| `--out 파일` | 보고서 경로(기본 `probe-report.json`) |
| `--full` | 보고서에 글 전체를 남깁니다 |
| `--print-lines` | 화면에 찍을 트리 줄 수(기본 150) |

`windows` 명령에는 `--all`(숨은 창까지 보기)과 `--json`이 있습니다.
